Rapid Reporter - Portable Deployment
=====================================

This folder contains all files needed to run Rapid Reporter.

Requirements:
- Windows 10/11 (64-bit)
- .NET 9.0 Runtime (Desktop) installed
  Download from: https://dotnet.microsoft.com/download/dotnet/9.0

To Run:
-------
Double-click RapidReporterEx.exe

Important Files:
----------------
- RapidReporterEx.exe       : Main application
- RapidReporterEx.dll       : Application library
- System.Management.dll     : System management library
- runtimes/                 : Native platform dependencies (DO NOT DELETE)
- *.png files               : UI icons
- RapidReporter.ico         : Application icon

Notes:
------
- Session files and screenshots will be saved in this folder
- A _rrlog_.log file can be created here to enable debug logging
- Do not delete the runtimes/ folder - it contains required native libraries
